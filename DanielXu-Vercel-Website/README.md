# Daniel Xu — Birthday Edition

A custom birthday website celebrating Daniel Xu, the one and only Beijing Beast.

## Deploy on Vercel

1. Import this GitHub repository at <https://vercel.com/new>.
2. Keep the detected framework as **Next.js**.
3. Leave the root directory and build settings at their defaults.
4. Click **Deploy**.
5. In the Vercel project, open **Settings → Domains** and add `danielxu.blog`.

The site is configured for the free Vercel Hobby plan and requires no
environment variables.
